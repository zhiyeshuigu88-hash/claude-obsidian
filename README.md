# claude-obsidian

Claude と Obsidian を連携させた個人用ナレッジベースです。

## 構成

```
claude/
  diary/          # 日記・作業ログ（「## タスク」に1日のタスク）
  weekly/         # 週のノート（その週の日曜日の日付で作成）
  tasks/          # 繰り返しタスクの設定など
  知識の保管庫/   # 学習メモ・調査まとめ
.obsidian/        # Obsidian 設定ファイル
```

## 使い方

[Obsidian](https://obsidian.md) でこのフォルダを保管庫として開いてください。

## プラグイン

- **realclaudian** — Claude と Obsidian をつなぐカスタムプラグイン（PC専用）
- **day-week-tasks**（今日・今週のタスク）— 1日ごと・1週間ごとのタスク管理（PC・スマホ両対応）
  - 左のリボンのカレンダーアイコンで、サイドバーに「今日 / 今週」の画面を開く
  - 「今日を始める」で前日の未完了タスクを繰り越し、繰り返しタスクを追加
  - 「今週のタスクから選ぶ」で週のタスクを今日に割り振る（日で完了すると週も完了）
  - 繰り返しタスクは `claude/tasks/繰り返し.md` に書く
