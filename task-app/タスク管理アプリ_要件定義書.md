| 項目 | 内容 |
|---|---|
| 作成日 | 2026-07-11 |
| バージョン | v1.1 |
| 対象 | 個人開発プロジェクト |
| ステータス | ドラフト（レビュー前） |

---

## 1. プロジェクト概要

### 1.1 目的
日々のタスクを一元管理しつつ、「決めた時間に、決めた作業を、集中して行う」ことを支援する個人用タスク管理アプリを開発する。単なるToDoリストではなく、**タイムボクシング**と**ポモドーロテクニック**を組み合わせ、計画と実行のギャップを埋めることを目指す。

### 1.2 想定ユーザー
- 個人利用（開発者本人を主ユーザーと想定）
- ITツールの利用に抵抗がなく、生産性向上に関心がある層

### 1.3 対象プラットフォーム
| プラットフォーム | 対応 |
|---|---|
| Webアプリ（PC） | ◯ |
| スマートフォンアプリ | ◯ |
| データ同期 | Web/スマホ間でリアルタイムに同期 |

### 1.4 スコープ外（今回は対象外とするもの）
- チーム／複数人での共有・コラボレーション機能
- 第三者への公開・マルチテナント対応
- 通知・リマインダー機能（将来検討）
- 外部カレンダー（Googleカレンダー等）との連携（将来検討）

---

## 2. 用語定義

| 用語 | 定義 |
|---|---|
| タスク | 実行すべき作業の最小単位。タイトル・期限・優先度等を持つ |
| ポモドーロ | 25分作業＋5分休憩を1セットとする時間管理手法（時間は可変） |
| タイムボックス | アプリ内で「この時間帯にこの作業をする」と確保した時間枠 |
| タイムボクシング | タスクを具体的な時間枠に割り当てて計画するスケジューリング手法 |

---

## 3. 機能要件

### 3.1 タスク管理（基本機能）
| ID | 機能 | 内容 |
|---|---|---|
| F-01 | タスクCRUD | タスクの作成・編集・削除・完了切替 |
| F-02 | 優先度設定 | 高・中・低など、タスクへの優先度付与 |
| F-03 | カテゴリ／タグ | タスクへの分類タグ付け、タグでの絞り込み |
| F-04 | 期限設定 | 日付＋時刻での締切設定 |
| F-05 | サブタスク | 1タスクに対する子タスクの追加 |
| F-06 | 並び替え・絞り込み | 期限順・優先度順の並び替え、完了/未完了フィルタ |

### 3.2 ポモドーロタイマー機能
| ID | 機能 | 内容 |
|---|---|---|
| F-10 | タイマー設定 | 作業時間・休憩時間を分単位でカスタマイズ可能（デフォルト25/5分） |
| F-11 | タイマー操作 | 開始・一時停止・スキップ・リセット |
| F-12 | タスク紐付け | 実行中タイマーを特定のタスクに紐付け、作業時間を記録 |
| F-13 | セッション記録 | 完了ポモドーロ数・実績時間の履歴保存 |
| F-14 | 実績可視化 | 日次／週次でのポモドーロ実施数の集計表示 |

### 3.3 タイムボクシング機能（アプリ内カレンダー／タイムライン）
| ID | 機能 | 内容 |
|---|---|---|
| F-40 | 時間枠の作成 | アプリ内タイムライン上でタスクに時間枠をドラッグ操作等で割当 |
| F-41 | 1日のスケジュール可視化 | 時間帯ごとにブロック表示、空き時間の把握 |
| F-42 | ポモドーロとの連動 | 1タイムボックス＝Nポモドーロとして設定し、時間枠内での消化状況を表示 |
| F-43 | 未消化タスクの繰越 | 時間枠内に終わらなかったタスクを翌日枠へ繰越提案 |

---

## 4. 非機能要件

| 分類 | 要件 |
|---|---|
| 性能 | タスク一覧・タイムライン表示は1秒以内に描画完了すること |
| 可用性 | オフライン時も直近のタスク閲覧・完了操作は可能とする（同期は復帰後） |
| セキュリティ | 認証必須、通信は全てHTTPS。個人データの第三者提供なし |
| ユーザビリティ | スマホ操作を前提としたタップ操作しやすいUI、片手操作を考慮 |
| 拡張性 | 将来の通知機能・カレンダー連携・チーム利用機能追加を見据えたデータ設計 |
| 対応環境 | モダンブラウザ（Chrome/Safari最新版）、iOS/Android実機 |

## 5. 画面一覧（想定）

| 画面名 | 概要 |
|---|---|
| ホーム／今日のタスク | 本日期限・本日のタイムボックス一覧を表示 |
| タスク一覧 | 全タスクの管理、フィルタ・並び替え |
| タスク詳細／編集 | 個別タスクの詳細確認・編集・サブタスク管理 |
| ポモドーロタイマー | タイマー操作画面、実行中タスクの表示 |
| タイムライン／スケジュール | 日／週表示、タイムボックスのドラッグ配置 |
| 実績・統計 | ポモドーロ実施数、タスク完了率などの可視化 |
| 設定 | タイマー時間設定などアプリ全体設定 |

---

## 6. データ要件（主要エンティティ）

| エンティティ | 主な属性 |
|---|---|
| Task | id, title, description, due_date, priority, tags, status, parent_task_id |
| PomodoroSession | id, task_id, start_time, end_time, duration, type（作業/休憩） |
| TimeBox | id, task_id, start_time, end_time, planned_pomodoros |

## 7. 想定技術スタック

過去の開発実績（React／Next.js、React Native／Expo、Supabase）を踏まえた案。要件確定後、技術選定として別途詳細化推奨。

| レイヤー | 候補技術 |
|---|---|
| Web フロントエンド | React（Next.js） |
| モバイル | React Native（Expo） |
| バックエンド／DB | Supabase（Auth・Postgres・リアルタイム同期） |

---

## 8. 制約条件・前提条件

- 個人開発のため、リソース（開発時間）は限定的
- 初期リリースはオフライン編集の完全同期までは対応しない（閲覧のみ許容）
- 通知機能・外部カレンダー連携は今回のスコープに含めない（将来検討事項）
