# Roland Rubix22 机下マウントホルダー 要件定義書

## 1. 背景・目的

現在、Roland Rubix22（USBオーディオインターフェース）は机の天板の上に平置きされており、Stream Deck・ゲームパッド・キーボードなどと天板スペースを共有している状態。天板上のスペース確保と配線の取り回し改善のため、Rubix22を**天板裏にネジ固定するマウントホルダー**を3Dプリントで自作する。

本ドキュメントは、Claude Codeでパラメトリック3Dモデル（OpenSCAD）を生成させるための要件定義書。

## 2. 対象製品仕様（Roland Rubix22）

| 項目 | 値 |
|---|---|
| 外形寸法（W×D×H） | 145 × 165 × 46 mm |
| 質量（本体のみ） | 約1.0 kg |
| 底面 | ゴム足（4隅、簡易な突起） |
| 前面パネル | SENS 1L/2R つまみ、INPUT 1L/2R（コンボ端子）、Hi-Z、OUTPUT・ヘッドホンつまみ、48V |
| 背面パネル | OUTPUT（1L/2R）、MIDI IN/OUT、USB、DC 5V電源、GROUND LIFT |
| 参考 | https://www.roland.com/jp/products/rubix22/ |

## 3. 現状（写真所見）

- Rubix22は天板上に横向き（前面パネルが手前）に平置きされている
- モニターアーム、Stream Deck、ゲームパッドコントローラー、キーボードと同じ天板スペースを共有し、手狭
- モニターアームの支柱・クランプが机奥にあり、天板下にもある程度の障害物（アーム基部）が存在する想定
- 天板は木目調の板（一般的なパーティクルボード/MDF系と推定）

## 4. 取り付け条件（ヒアリング確定事項）

| 項目 | 内容 |
|---|---|
| 固定方式 | **ネジ固定式**（天板裏に直接ネジ止め） |
| 天板厚さ | **約2cm（薄め）** → ネジ長は板厚を貫通しない長さに要注意 |
| 操作頻度 | **つまみ操作・ケーブル抜き差しはたまに行う程度**（常時アクセス必須ではないが、完全に隠蔽もしない） |
| 想定プリンター | Bambu Lab A1 mini（ビルドボリューム 180×180×180mm） |
| 想定材料 | PLA（既存のフィラメント保管環境あり） |

## 5. 機能要件

| No. | 要件 | 詳細 |
|---|---|---|
| F-1 | 本体保持 | Rubix22（145×165×46mm、約1.0kg）を落下せず安定して保持できること |
| F-2 | 天板裏ネジ固定 | 天板厚2cm前後を想定し、天板を貫通しないネジ長（目安12〜15mm程度のネジが使える設計）でホルダー本体を固定できること。ネジ穴位置・径はホルダーのフランジ部に設計する |
| F-3 | 着脱可能 | Rubix22本体はホルダーに対して**スライド挿入 or 半クリップ式**などで着脱可能とし、取り外して机上で使うことも可能にする（ネジ止めするのはホルダー側のみで、本体は非破壊で脱着できる） |
| F-4 | 前面アクセス確保 | SENS/Hi-Z/48Vなど前面パネルのつまみ・ジャックが指で操作できるよう、前面は覆わない、または大きく開口する |
| F-5 | 背面ケーブル取り回し | 背面のUSB・DC・MIDI・OUTPUT端子付近は開口し、ケーブルを挿したまま着脱できるスペースを確保 |
| F-6 | 落下防止機構 | ネジ止めだけに頼らず、本体の自重（1.0kg）を受けるリブ/底面リップを設け、経年でのプラスチック疲労・ネジ緩みでも即落下しない構造とする |
| F-7 | 通気 | 底面全面を塞がず、放熱用のスリット/開口を設ける |

## 6. 非機能要件

| No. | 要件 | 詳細 |
|---|---|---|
| N-1 | 分割印刷対応 | Bambu Lab A1 mini（180×180×180mm）のビルドボリュームに収まるよう、必要なら2〜3パーツに分割し、ネジまたは接着で結合する設計とする |
| N-2 | 強度 | PLA積層時、荷重方向（機器の自重）に対してレイヤーが割れにくい向きで印刷できる形状にする（設計時にプリント方向をコメントで明記） |
| N-3 | サポート材最小化 | オーバーハングを極力避け、印刷サポートが最小限で済む形状にする |
| N-4 | 調整可能性 | OpenSCADのパラメータ（機器寸法、クリアランス、ネジ穴径・ピッチ、板厚想定など）を変数化し、実測後に微調整できるようにする |

## 7. 成果物

| 成果物 | 内容 |
|---|---|
| `rubix22_mount.scad` | パラメトリックOpenSCADソースファイル（寸法・クリアランス等を変数管理） |
| `rubix22_mount.stl`（複数可） | スライサーに読み込む出力ファイル。分割時はパーツごとに出力 |
| 簡易組み立て手順メモ | ネジの種類・本数・取り付け手順を記載したテキスト |

## 8. 制約・注意事項

- 天板厚は「約2cm」という目安のみで実測値ではないため、**印刷前に現物のノギス／メジャーでの実測を推奨**（ネジ穴位置・フランジ厚に直結するため）
- 天板裏のモニターアーム基部や配線と干渉しない位置に取り付ける必要があり、実際の設置位置（アームからの距離）は現物合わせで決める
- 使用するネジは天板材質（パーティクルボード/MDF/集成材等）が不明なため、木ネジを想定しつつ、下穴径はホルダー側で余裕を持たせる

## 9. 未確定・要確認事項（着手前に確認したい点）

1. Rubix22を**前面が正面を向く向き**（操作しやすい）と**側面を正面に向ける向き**（省スペース）のどちらで固定したいか
2. 取り付け予定位置（モニターアーム基部からの距離、天板のどのあたりか）の実測値
3. 使用予定のネジ（手持ちの木ネジのサイズ）があるか、それとも新規購入前提か

---
必要であれば、上記の要件でこのままClaude Codeに渡してOpenSCADモデルの生成を進められます。
