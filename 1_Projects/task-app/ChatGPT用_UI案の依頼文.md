あなたはプロダクトデザイナーです。個人用のタスク管理アプリ「Focus Task」の見た目（UI）を作り直したいので、方向性の違うデザイン案を3つ作ってください。

## アプリの概要
- 名前: Focus Task（1人で使う、タスク管理 + ポモドーロ + 習慣 + タイムライン）
- 使い方: PC のブラウザと、スマホ（PWA としてホーム画面に追加）の両方で使う
- 技術: 素の HTML / CSS / JavaScript（フレームワークなし）。案は「HTML + CSS で再現できるもの」にしてください

## 画面と機能（日本語UI）
1. Home
   - ポモドーロタイマー（作業 25 分 / 休憩 5 分、開始・一時停止・スキップ・リセット、紐付けるタスクまたは習慣の選択）
   - 本日期限のタスク
   - 今日の習慣（丸いチェックで達成を記録、時間帯・繰り返し・連続日数のチップ、達成数 x / y）
   - タスク一覧（絞り込み: 未完了/完了/すべて、並び順: 期限順/優先度順、優先度とタグ付き、右上の「＋」で新規作成モーダル）
2. 日間ビュー: 6:00〜24:00 のタイムライン、時間枠（タスクを入れる）、習慣のブロック、「この日のタスク」「この日の習慣」
3. 週間ビュー: 7日のグリッド、今週の習慣（7日×習慣のチェック表）、未割り当てタスク（日付へドラッグ）、今週のサマリー（完了数・予定時間・完了率・習慣達成率・日ごとの負荷）
4. 習慣管理: 習慣カード（毎日 / 曜日指定 / 週◯回）、連続日数、今週の達成状況
5. 実績・統計: ポモドーロ回数、作業時間
6. 設定
- ナビゲーション: 左のハンバーガーメニュー（開閉式。「常に開く」固定も可能）

## 今のデザイン（「Organic」テーマ）
- 配色: 背景 #f5ead8（ベージュ）/ サーフェス #ebddc5 / 文字 #201e1d / アクセント テラコッタ #c67139 / サブアクセント セージ #7a8a5e（習慣はセージ系）
- フォント: 見出し Caprasimo / 本文 Figtree
- 形: ボタンは丸いピル型、カードは角丸 16px、モーダルは角丸大きめ
- 印象: 温かく柔らかいが、やや装飾が強く、情報が多い画面では詰まって見える

## 直したいこと
- 全体の見た目をもっとすっきり、洗練された印象にしたい
- 「集中して作業する」アプリらしい落ち着きと、使うのが楽しくなる要素の両立
- 情報が多い Home と週間ビューを、見やすく整理したい

## 作ってほしいもの
方向性の違う3案（例: ①ミニマル・モノトーン寄り ②今の温かさを活かしつつ整理 ③ダークテーマ中心）について、各案ごとに:
1. コンセプトを 2〜3 文で
2. 配色（色コードつき）、フォント、角丸・影・余白のルール
3. Home 画面のデザイン（PC とスマホの両方）。可能なら HTML + CSS のコードで
4. 日間ビューまたは週間ビューのデザイン（どちらか 1 つ）
5. ボタン・チップ・チェック・カード・モーダルなどの部品デザイン

## 条件
- 日本語の文字が読みやすいこと（本文 14px 前後、行間ゆったり）
- スマホ（幅 375px）でも崩れないこと
- ライトとダークの両対応が望ましい（無理なら案の中で明記）
- アクセシビリティ: 文字と背景のコントラストを十分に確保
