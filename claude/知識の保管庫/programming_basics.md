# プログラミング基礎の学習方法

---

## ステップ 1 — 言語を1つ選ぶ

個人開発（Web + モバイル）が目標なら **JavaScript** 一択です。
WebもモバイルもサーバーもJavaScript1本で対応できるため、基礎学習の投資効率が最も高いです。

---

## ステップ 2 — 基礎概念を順番に習得する

| 順番 | 概念 | 具体例 |
|:---:|---|---|
| 1 | 変数・データ型 | `let name = "田中"` / 数値・文字列・真偽値 |
| 2 | 条件分岐 | `if` / `else` / `switch` |
| 3 | ループ | `for` / `while` / `forEach` |
| 4 | 関数 | 処理のまとまりを部品化する |
| 5 | 配列・オブジェクト | データをまとめて扱う |
| 6 | 非同期処理 | `Promise` / `async/await`（API通信に必須） |

---

## ステップ 3 — 学習リソースの選び方

**完全無料でできる組み合わせがおすすめです：**

- **[MDN Web Docs](https://developer.mozilla.org/ja/)** — 信頼性最高の公式リファレンス。辞書的に使う
- **[The Odin Project](https://www.theodinproject.com/)** — 体系的な無料カリキュラム（英語）
- **Udemy** — セールで1,500円前後。「JavaScript 完全マスター」などが人気
- **ChatGPT / Claude** — わからない箇所をすぐ質問できる。詰まったら積極的に使う

---

## ステップ 4 — 学習サイクルを守る

```
読む（インプット）
  ↓ 30分以内
書く（手を動かしてコードを打つ）
  ↓
壊す（わざと変えて何が起きるか試す）
  ↓
作る（小さいものを自分で作る）
```

**「読むだけ」が一番の落とし穴です。** 手を動かす時間を全体の7割にしてください。

---

## ステップ 5 — 小さく作る

基礎を一通り触ったら、すぐに何か作り始めるのが最速です。

| 難易度 | 作るもの |
|:---:|---|
| 入門 | 電卓 / じゃんけんゲーム / ToDoリスト |
| 初級 | 天気表示アプリ（API使用）/ タイマー |
| 中級 | メモアプリ（DB保存）/ ログイン機能付きアプリ |

---

## よくある失敗と対策

- **完璧に理解してから進もうとする** → わからなくても先に進んでOK。後で繋がります
- **写経だけで終わる** → 必ず自分でゼロから書き直す時間を作る
- **詰まって止まる** → 30分悩んだら調べる or 質問する。時間を決めてください
